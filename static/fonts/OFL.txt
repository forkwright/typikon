SIL Open Font License (OFL) 1.1 — Attributions

The WOFF2 files shipped in this directory are subsets of three font
families distributed under the SIL Open Font License, Version 1.1.
Subsetting was performed with fonttools `pyftsubset`, requesting the
Latin (U+0000–00FF), Greek (U+0370–03FF), and Greek Extended
(U+1F00–1FFF) ranges for the serif families and Latin only for the
monospace family. pyftsubset keeps only glyphs that exist in the source
master, so requesting a range is not the same as shipping it: EB Garamond
carries real Greek and polytonic Greek Extended, while Spectral's upstream
master carries only the handful of letters it ships as math/science symbols
(Delta, mu, pi). See static/css/fonts.css for the exact per-file
unicode-range each file actually supports — those declarations are derived
from the shipped cmaps and verified by ci/check-font-coverage.py.

The OFL requires that every distribution preserve the copyright notice
of the original font. All three notices are reproduced below. The full
OFL 1.1 text is available at https://openfontlicense.org.
